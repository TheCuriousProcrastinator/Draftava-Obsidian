# Draftava Companion

[Get Draftava for macOS](https://offensivecaffeine.com/draftava/)

Send selected text, Markdown notes, and images from Obsidian directly to Draftava.

## Requirements

- Obsidian 1.12.0 or later.
- macOS with the Draftava application.
- Draftava is a separate application with its own licensing.

## Features

- Send selected text to Draftava.
- Send individual Markdown notes.
- Send multiple selected Markdown notes.
- Send local and remote images.
- Quickly capture using the floating Draftava action.

## Source links

Imported Ideas retain a clickable Source link to their original Obsidian note or vault file. The link uses the official obsidian:// URI scheme. The originating vault and file must remain available for the link to work.

## Usage

Select text or click an image to reveal the Draftava action. You can also right-click supported files and select Send to Draftava.

The plugin looks for a running Draftava application and otherwise uses /Applications/Draftava.app.

## Privacy

Content is sent to the Draftava application on your Mac. The plugin creates temporary capture files outside the Obsidian vault. Remote images may be downloaded from their source URLs.

## Compatibility

Desktop only, macOS. Obsidian Mobile is not supported.
